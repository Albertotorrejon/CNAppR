CNAppR

CNAppR is an R package for the integrative analysis of somatic Copy Number Alterations (CNAs) in cancer genomics. It extends the original CNApp 1.0 framework with a native BAM processing pipeline, adding direct support for whole-exome sequencing (WES), whole-genome sequencing (WGS), and liquid biopsy cell-free DNA at low tumour fractions — including low-pass Nanopore long-read data.

The package is self-contained: pre-computed GC correction tables for hg19 and hg38 eliminate the need for a reference FASTA file, and there are no dependencies on external command-line tools.

Installation

CNAppR is available from GitHub. Install with devtools:

You can install the development version of CNAppR from GitHub:

# install.packages("devtools")
devtools::install_github("Albertotorrejon/CNAppR")

Usage

BAM pipeline

For samples where you have a BAM file, use run_bam_pipeline() to go directly from raw reads to CNA scores: 

library(CNAppR)

# WES — Illumina whole-exome sequencing
result <- run_bam_pipeline(
  bam_path        = "tumor.bam",
  sequencing_type = "illumina",
  experiment_type = "wes",
  targets_bed     = "capture_kit.bed",
  genome_build    = "hg19"
)

# WGS — Nanopore cfDNA, low-pass
result <- run_bam_pipeline(
  bam_path        = "cfDNA.bam",
  sequencing_type = "nanopore",
  experiment_type = "wgs",
  bin_size        = 500e3,
  genome_build    = "hg38"
)

result$scores    # data.frame: BFB, HRD, CIN
result$segments  # segmented copy number profile

Pre-segmented data

CNAppR also accepts pre-segmented tables from SNP arrays, aCGH, or any upstream segmentation tool: 

# Load the bundled demo dataset (160 TCGA-COAD samples)
data <- read_cna_file(system.file("models", "demo.txt", package = "CNAppR"))

# Re-segment and score all samples
ids        <- unique(data$ID)
reseg_list <- lapply(ids, function(id) resegment_sample(data, sample_id = id))
names(reseg_list) <- ids

scores <- calculate_cna_scores(reseg_list)
head(scores)

Features

  • Native BAM processing — no FASTA, no external tools required
  • WES support with capture BED files and automatic target splitting
  • WGS support for Illumina short-read and Nanopore long-read data
  • cfDNA and liquid biopsy analysis at low tumour fractions
  • Pre-computed GC correction tables for hg19 and hg38 (500 kb–10 Mb bins)
  • Panel of Normals construction and application for tumour-only workflows
  • CBS segmentation with configurable sensitivity
  • CNA scores (FCS, BCS, GCS) validated on 160 TCGA-COAD samples
  • Gene annotation using bundled RefSeq tables for hg19 and hg38
  • Random forest classifier for molecular subtype prediction
  • Clinical association tests (parametric and non-parametric)

Reference

Documentation for all exported functions in CNAppR 1.1.0.

BAM Input Pipeline

read_bam_qc() Read a BAM file, tile into bins, count reads, and return GC-corrected log2 ratios
run_cbs_segmentation() Segment a log2-ratio track using Circular Binary Segmentation
build_pon() Build a Panel of Normals from a set of normal-sample BAM files
run_bam_pipeline() Full BAM-to-CNA-scores pipeline in a single call

Segmentation & Scoring

resegment_sample() Re-segment a sample with adjusted CBS parameters without repeating QC
calculate_cna_scores() Compute Focal (FCS), Broad (BCS) and Global (GCS) CNA scores from a segment table

Input & Validation

read_cna_file() Read a tab-separated or CSV CNA segment file into a data frame
validate_cna_data() Validate required columns and normalise chromosome labels in a CNA data frame

Annotation

annotate_cna_genes() Map CNA segments to overlapping RefSeq genes using bundled hg19/hg38 tables

Visualisation

plot_segmentation() Plot original and re-segmented copy number profiles side by side for a single sample
plot_cn_frequency() Plot genome-wide copy number gain/loss frequency across a sample collection

Clinical Analysis

test_clinical_association() Parametric and non-parametric tests linking CNA scores to clinical variables

Changelog

CNAppR 1.1.0
2026-05-20
New features
  • New BAM input pipeline: read_bam_qc(), run_cbs_segmentation(), build_pon(), and run_bam_pipeline() allow end-to-end analysis directly from .bam files without preprocessing or external tools.
  • Support for Illumina whole-exome sequencing (WES) with capture BED files. Target intervals are automatically split into sub-bins for finer resolution.
  • Support for whole-genome sequencing (WGS) with both Illumina short-read and Oxford Nanopore long-read data. Validated on low-pass cfDNA from colorectal cancer patients (liquid biopsy).
  • Panel of Normals (build_pon()): construct a per-bin median reference from normal-sample BAMs and apply it to tumour samples to remove systematic technical biases in tumour-only workflows.
  • Pre-computed GC correction tables for hg19 and hg38 at bin sizes of 500 kb, 1 Mb, 2 Mb, and 10 Mb, bundled in inst/extdata/. No reference FASTA download required.
  • Automatic chromosome naming normalisation: the BAM reader handles both UCSC (chr1) and Ensembl/NCBI (1) conventions, including chrM → MT conversion for GRCh37 BAMs.
Changes
  • use_antitarget now defaults to FALSE in read_bam_qc(). Off-target antitarget bins are opt-in only; typical users supplying a BAM and a capture BED do not need them.
  • split_targets defaults to NULL, which automatically resolves to TRUE for WES experiments.
  • Removed render_validation_report() and the bundled validation_report.Rmd. Validation analyses are no longer distributed with the package.
CNAppR 1.0.0
2025
Initial release
  • Re-segmentation engine based on iterative segment merging with configurable deviation thresholds (dev_btw_segs, dev_tozero).
  • CNA scoring: Focal CNA Score (FCS), Broad CNA Score (BCS), and Global CNA Score (GCS), validated on 160 TCGA-COAD colorectal cancer samples (Franch-Exposito et al., eLife 2020).
  • Gene annotation for hg19 and hg38 using bundled UCSC RefSeq reference tables.
  • Random forest classifier for molecular subtype prediction from CNA scores. Pre-trained model included; no retraining required.
  • Visualisation: genome-wide segmentation plots (plot_segmentation()) and copy number frequency heatmaps (plot_cn_frequency()).
  • Clinical association module: parametric and non-parametric tests linking CNA scores to survival, treatment response, and clinical covariates.
  • Bundled demo dataset of 160 COAD samples with clinical variables (system.file("models", "demo.txt", package = "CNAppR")).
